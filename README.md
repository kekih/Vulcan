# Vulcan — Плагин вулканов для Paper 1.16.5

Полноценная система автоматических вулканов в игровом мире по техническому заданию.

## Особенности

- **Три типа вулканов**: Обычный, Легендарный (самый ценный), Мифический (самый редкий)
- Автоматическое появление каждые **4 часа** (настраивается)
- Физическая структура вулкана строится в мире (конус из blackstone / basalt / magma, кратер с лавой)
- Таймер **6 минут** до извержения с нарастающими эффектами
- Зрелищное извержение: частицы дыма, лавы, огня, пепла + звуки
- Предметы физически выбрасываются в мир (игроки подбирают сами)
- Награды и шансы настраиваются отдельно для каждого типа
- Добавление предметов из руки: `/vulcan add <тип>`
- Полное сохранение таймеров после рестарта сервера
- Только одна команда для игроков: `/vulcan info`
- Все сообщения на русском языке

## Установка

1. Скачайте `Vulcan.jar` из Releases или соберите сами (`mvn package`)
2. Положите в папку `plugins` сервера Paper 1.16.5
3. Перезапустите сервер
4. Настройте координаты: встаньте в нужное место и выполните  
   `/vulcan setlocation normal`  
   `/vulcan setlocation legendary`  
   `/vulcan setlocation mythical`
5. Добавьте награды, держа предмет в руке:  
   `/vulcan add normal` и т.д.
6. Настройте шансы: `/vulcan setchance normal 0 25`

## Команды

### Для игроков
| Команда | Описание |
|---------|----------|
| `/vulcan info` | Информация о текущем / следующем вулкане |

### Для администраторов (`vulcan.admin`)
| Команда | Описание |
|---------|----------|
| `/vulcan spawn <тип>` | Вызвать вулкан вручную |
| `/vulcan despawn` | Удалить активный вулкан |
| `/vulcan setlocation <тип>` | Сохранить текущие координаты |
| `/vulcan setinterval <сек>` | Интервал появления (по умолчанию 14400) |
| `/vulcan setduration <сек>` | Время до извержения (по умолчанию 360) |
| `/vulcan add <тип>` | Добавить предмет из руки в награды |
| `/vulcan remove <тип> <номер>` | Удалить награду |
| `/vulcan setchance <тип> <номер> <шанс>` | Установить шанс выпадения |
| `/vulcan check <тип>` | Посмотреть список наград |
| `/vulcan list` | Список типов и шансов появления |
| `/vulcan timer` | Время до следующего события |
| `/vulcan reload` | Перезагрузить конфигурацию |
| `/vulcan help` | Справка |

Типы: `normal`, `legendary`, `mythical`

## Права

- `vulcan.admin` — полный доступ (по умолчанию op)
- `vulcan.info` — доступ к `/vulcan info` (по умолчанию true)

## Конфигурация

Основные параметры в `config.yml`:

```yaml
settings:
  spawn-interval: 14400      # 4 часа
  eruption-delay: 360        # 6 минут
  one-active-vulcan: true
  restore-timer-after-restart: true
  drop-radius: 8
  drops-min: 8
  drops-max: 18
```

Шансы появления типов (веса):
- normal: 75
- legendary: 20
- mythical: 5

## Структура вулкана

Плагин строит физический конус в стиле событий FunTime:
- Основание из blackstone / basalt / netherrack
- Магма-блоки внутри и в кратере
- Лава в центре кратера
- Для Legendary/Mythical — дополнительные декорации (обсидиан, огонь)

Точная схематика FunTime в открытом доступе отсутствует, поэтому реализована процедурная постройка. При желании можно поставить свою схематику WorldEdit и указать координаты кратера через `/vulcan setlocation`.
